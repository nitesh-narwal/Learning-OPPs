## 🎯 Key Learnings at a Glance

### Quick Reference Table

| Type | Syntax | Instance Required | Use When |
|------|--------|-------------------|----------|
| **Member** | `outer.new Inner()` | YES | Need outer state |
| **Static** | `new Outer.Inner()` | NO | Utility/Factory |
| **Local** | In method only | N/A | Method-specific |
| **Anonymous** | `new Intf() {...}` | N/A | One-time use |
| **Lambda** | `(a,b) -> {...}` | N/A | Functional IF |

### Decision Tree

```
Do you need outer instance?
├─ YES → Member Inner Class
└─ NO  → Static Inner Class

Is it method-specific?
├─ YES → Local Inner Class
└─ NO  → (see above)

Is it one-time use?
├─ Functional interface (1 method)
│  ├─ Simple logic → Lambda
│  └─ Complex logic → Anonymous
└─ Multiple methods → Anonymous Class
```

- Make sure all .java files are in the same directory
- Java version should be 8 or later (for lambda support)
- Use `javac *.java` to compile everything

### Runtime Issues
- Use `java InnerClassesMain` from the same directory
- If classes not found, ensure compilation was successful
- Check that Step*.java files are present

- Re-read the detailed comments in each file
- Run the examples and observe the output
